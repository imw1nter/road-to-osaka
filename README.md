# Road to Osaka 🏃

A marathon training hub for the Osaka Marathon 2027 — Web Programming course project.

**Live site:** https://imw1nter.github.io/road-to-osaka/

## Pages
| Page | Purpose |
|---|---|
| `index.html` | Start screen: race countdown, weekly summary, weather, coach note |
| `log.html` | Add runs and view past runs |
| `stats.html` | Charts and personal bests |
| `plan.html` | Training plan with completion checkboxes |
| `coach.html` | AI weekly review and Q&A |
| `race.html` | Osaka Marathon info and race-day checklist |

## Tech
HTML, CSS, JavaScript, DOM, Web APIs (Fetch, Geolocation, Canvas, localStorage), Firebase, GitHub Pages, serverless AI function.
